# Shyan Shah

MEng Mechanical Engineering at the University of Bath (graduating 2028). Most of my work sits where hardware meets code: a physical thing gets designed, built and simulated, then made to talk to software.

## Projects

**[Vita](https://github.com/shyan-shah/leukerbad-hack)**. Turns an off the shelf, force sensing robot arm (Flexiv Rizon 4) into an arm rehabilitation station. The arm acts as an elastic band at four resistance levels, counts every rep and measures force and range. A physio follows each session remotely. FastAPI server with a 30 Hz WebSocket feed, a 100 Hz control loop, and a single safety layer as the only code that touches the robot. Built in 48 hours by a team of five at the Leukerbad Robot Carnival (Nov 2026). Research prototype, team tested only. [vitarehab.org](https://vitarehab.org)

**[Robot penguin](https://github.com/shyan-shah/robot-penguin)**. A 23 cm desk robot that waddles, talks, dances and reacts to people. Seven servos, an ESP32-S3 and a 580 g printed shell. The physics simulation is built from the CAD, and the firmware's motion tables are generated from the simulation, so what gets printed is what was tested. Includes parametric CAD, print ready STLs, MATLAB/Simulink stability analysis and a full build log. Designed and simulated, physical build in progress.
