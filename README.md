## Shyan Shah

Mechanical engineering student at the University of Bath (MEng, integrated master's), currently on industrial placement at Bentley Motors. I build things across three areas: engineering, endurance sport, and entrepreneurship.

Most of my work sits at the point where hardware meets code. I like problems where a physical thing has to be designed, built, and then made to talk to software that turns raw signal into something useful.

### What I'm building

**AeroLab** — an open-source, low-cost instrument for measuring cycling aerodynamics in the field. An ESP32 reads a pitot-static airspeed sensor at high frequency, logs it against GPS, and a Python pipeline fuses that with power-meter data to correct field CdA estimates for ambient wind. Validated against wind-tunnel data. Built to give amateur athletes a ~£150 alternative to £450 tunnel sessions.

**FlowLocal** — a local, offline voice-to-text tool built on Whisper, with a command mode for voice-driven editing and per-application writing styles.
